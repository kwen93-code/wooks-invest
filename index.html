나만의 상품·전략 추가

연구 업데이트 가져오기

중요: 현재 ChatGPT 대화와 앱이 자동 연결되지는 않습니다. 이 대화에서 만든 분석 업데이트를 JSON으로 가져오거나, 향후 공개 데이터 주소를 연결해야 합니다. 별도 연동 없이 GPT 메시지가 자동 반영되는 것으로 표시하지 않습니다.

앱에 저장된 전략 데이터를 JSON 파일로 내보내고, 새 분석 파일을 가져오면 모든 상품 목록과 연구 노트를 갱신합니다. 가족 기기에는 같은 업데이트 파일을 전달할 수 있습니다.

JSON 직접 붙여넣기

향후 자동 데이터 주소

앱을 https 웹사이트로 배포한 뒤 CORS를 허용하는 공개 JSON 주소를 입력하면 앱을 열 때 최신 데이터를 조회할 수 있습니다. 아직 GPT 대화 자동 연결 기능은 아닙니다.

설치 및 가족 공유

ZIP을 정적 웹 호스팅에 배포하면 아이폰 Safari의 '홈 화면에 추가', 갤럭시 Chrome의 '앱 설치/홈 화면에 추가'로 앱처럼 사용할 수 있습니다. 파일을 단독으로 열면 PWA 설치·자동 업데이트가 제한됩니다.
